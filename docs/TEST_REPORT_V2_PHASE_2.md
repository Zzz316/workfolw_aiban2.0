Phase 2 的 Mock 自动化闭环已通过，现有线性顺序状态机能够完成步骤推进并产生 OK、NG、TIMEOUT、INTERRUPTED 等终态。真实 SDK 环境已有帧、标签匹配和 NG 结果证据，但尚未形成真实 OK、截图和 MySQL 成功落库的正式验收记录。

## 4. 架构限制

1. 当前主流程以线性 `aiban-label` 链表达顺序逻辑，尚不能统一表达计数、时长、无序集合、外部信号、循环和组合条件。
2. `aiban-result` 同时承担结果生成、流程收尾和部分副作用编排，职责偏重，降低了逻辑复用性。
3. 现有业务节点尚未统一消费标准 `msg.outcome` 合同。
4. 场景注册、版本、启停、路由和恢复能力尚未实现。

这些限制分别由 T05～T08、T09～T15 和 T19～T21 处理。
