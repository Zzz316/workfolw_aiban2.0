## 4. 当前架构基线

当前主数据通路为：

```text
AiBan SDK
  → Python Runner
  → stdout JSONL
  → aiban-runtime
  → msg.aiban
  → aiban-label / aiban-sequence
  → aiban-result
  → 日志、数据库等副作用
```

已确认的基础能力：

- Node-RED 节点托管 Python Runner；
- JSONL 控制命令和运行时事件；
- SDK 帧、标签、框及元数据标准化；
- 单一线性顺序逻辑的 Mock OK/NG/TIMEOUT/INTERRUPTED 闭环；
- 审计日志、结果汇总和数据库写入节点基础能力。

尚未具备的目标能力：

- 统一、可验证的运行时状态控制器；
- 解耦后的 Logic Outcome 与 Result Contract；
- 场景注册、启停、路由、持久化和恢复；
- 多种逻辑类型的统一配置与组合；
- 完整生产实测与长稳验收。

## 6. 当前已知缺陷和风险

| 编号 | 问题 | 影响 | 任务 |
|---|---|---|---|
| B-001 | 编辑器按钮以 `autoStart` 等配置值近似表示运行状态 | UI 与真实进程可能不一致 | T01、T02 |
| B-002 | 管理接口、编辑器按钮和消息命令各自控制运行时 | 可能出现重复启动、竞态和反馈不一致 | T01、T02 |
| B-003 | Python Runner 重启复用停止路径，停止事件可能未正确复位 | 重启后可能短暂 ready 随即退出 | T03 |
| B-004 | 现有重启测试未验证第二次 ready 后持续存活 | 缺陷可能被假阳性测试掩盖 | T03、T04 |
| B-005 | `aiban-result` 同时承担判定收尾、结果组装及副作用编排 | 逻辑配置通用性和复用性不足 | T05～T08 |
| B-006 | 无正式场景模型 | 多场景启停、隔离和恢复无法统一实现 | T09～T15 |
| B-007 | 缺真实 OK、截图、MySQL 成功及 24 小时稳定性证据 | 暂不能判定生产闭环完成 | T16～T18、T22 |
